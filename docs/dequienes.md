# Chile: DeQuienes → RES

Актуальный конвейер этапов 1–3: [настройки, очереди и запуск](dequienes-pipeline.md).

План следующих этапов, очередей, браузеров и прокси: [dequienes-implementation-plan.md](dequienes-implementation-plan.md).

Исходный процесс: [Tango DeQuienes](https://app.tango.us/app/workflow/Workflow-with-Dequienes-b74246fb18a34359bbe1c4bc98d8c3ac)
и [Tango RES Verificar Certificados](https://app.tango.us/app/workflow/Workflow-with-Registrodeempresasysociedades-06725ee11ad04623b0d1469355c5fbaf).
Название/RUT → компания → Legal → таблица Eventos Legales. Собираются дата,
тип, источник, CVE (с сохранением регистра) и описание. В примере Tango:
AERO INSPECCIONES SPA, 77.755.694-0, 07/05/2023, CONSTITUCIÓN, ACiWqbFTpsmy.
Aero — только пример запроса, а не обязательный фильтр.

Второй Tango проверен: вставить CVE → пройти «I’m not a robot» → Verificar →
скачать PDF. Финальный скриншот показывает встроенный просмотрщик Chrome:
`ACiWqbFTpsmy.pdf`, 9 страниц, «CONSTITUCIÓN DE SOCIEDAD POR ACCIONES»,
AERO INSPECCIONES SpA, 07/05/2023. Это подтверждение результата в записи Tango,
а не успешное скачивание текущим парсером. Buscar Actuaciones исключён из
актуального процесса. Количество компаний/документов в обоих Tango не задано.

Артефакты проверки: `data/dequienes-camoufox-probe/{landing,search}.{html,png}`.
Ни одного PDF в этой проверке не скачано.

RES использует reCAPTCHA. Обработчик кнопки отправляет JSON `{texto, Response}`
в `VerificarCertificados.aspx/Busqueda`. Ответ `d` содержит JSON с `ErrorMessage`
и `Link`; при успехе браузер переходит по Link. Документ извлекается только по
ссылке, возвращённой этим обработчиком, с той же браузерной сессией.
Прямой публичный URL PDF по одному CVE не подтверждён.

## Сбор названий компаний из публичного архива

Отдельный первый этап без аккаунта и RES:

Для одного месяца: `bash scripts/dequienes_companies.sh --year 2025 --month 1 --workers 2 --delay 0.3 --output data/dequienes-companies-2025`. Обрабатывается только январь, существующая база сохраняется. Второй процесс с тем же профилем или базой отклоняется блокировкой. Если Camoufox не запускается, сначала закройте предыдущий процесс/браузер этого профиля; размер выбранного периода на запуск браузера не влияет.

```bash
# Все публикации выбранного года (без ограничения количества).
bash scripts/dequienes_companies.sh --year 2025 --workers 4 --delay 0.3 \
  --output data/dequienes-companies-2025

# Первые 10 ещё не собранных публикаций месяца.
bash scripts/dequienes_companies.sh --month 2026-11 --limit 10

# Продолжить месяц: уже собранные URL пропускаются, ошибки повторяются.
bash scripts/dequienes_companies.sh --month 2026-11

# Несколько месяцев или весь архив (длительный запуск).
bash scripts/dequienes_companies.sh --month 2026-10 --month 2026-11
bash scripts/dequienes_companies.sh --all-months
```

`--year` выбирает все доступные месяцы года из sitemap-index. Для текущего
года это только опубликованные месяцы; для отсутствующего года запуск завершится
ошибкой. Выгрузка охватывает компании из публикаций Diario Oficial за этот год,
а не все зарегистрированные компании Чили. Для каждого года рекомендуется
отдельный `--output`, поскольку CSV содержит все результаты его базы.

Без выбора года или месяца используется самый новый месяц из sitemap-index. `--limit`
ограничивает количество страниц публикаций в текущем запуске, не количество
уникальных компаний. По умолчанию работают 4 HTTP-обработчика с общей сессией, автоматически подготовленной Camoufox.
`--workers` задаёт число одновременных обработчиков; `--delay` — паузу каждой
вкладки между публикациями (по умолчанию 1 секунда). Для последовательного
режима используйте `--workers 1`. Задания распределяются без повторного
назначения, результаты пишутся в SQLite сразу после обработки. При трёх
ошибках подряд новые задания перестают выдаваться, начатые завершаются.

Если уже запущена старая версия, остановите её через Ctrl+C и повторите
команду с тем же `--output` и нужным `--workers`: собранные страницы пропускаются.
Один профиль и одну базу не следует одновременно использовать в двух процессах.

В `--output` (по умолчанию `data/dequienes-companies`) сохраняются:

- `publications.csv`: название из h1, RUT при наличии в заголовке, дата,
  исходная ссылка и полный заголовок публикации.
- `companies.csv`: уникальные названия, количество публикаций, диапазон дат
  и пример исходной ссылки.
- `companies.sqlite3`: очередь и результаты для продолжения после остановки.
- `summary.json`: количества collected/pending/failed и уникальных названий.
- `errors/`: HTML страниц, которые не удалось распознать после трёх попыток.

Список месяцев берётся с сайта, а не зашит в код. Проверено 189 месяцев,
03/2011–11/2026. Названия извлекаются со страниц, а не восстанавливаются из
URL: это сохраняет акценты, регистр и знаки препинания. Повторяющиеся названия
объединяются без учёта регистра после Unicode-нормализации. Это список названий,
а не установленных уникальных юридических лиц: компании могут переименовываться,
а разные юридические лица могут иметь одинаковые названия. Упоминания других
компаний в тексте публикации на этом этапе не извлекаются.

Живая проверка: 10 публикаций ноября 2026 → 10 названий, 0 ошибок;
артефакты в `data/dequienes-companies-pilot`. Доступность CVE RES для этих
компаний ещё не проверена.

## Запуск

Используются уже установленные в проекте зависимости и браузер Camoufox:

```bash
export PYTHONPATH="$PWD/.camoufox-deps:$PWD"
export XDG_CACHE_HOME="$PWD/data/camoufox-cache"

# Диагностика поиска, HTML, скриншот, report.json; код 1 при требовании входа.
.venv/bin/python -m src.sites.dequienes --query Aero --discover-only

# На рабочем столе: войти вручную в отдельном постоянном профиле,
# затем выбрать компанию и открыть Legal по подсказкам в терминале.
.venv/bin/python -m src.sites.dequienes --query Aero --interactive \
  --company-name 'AERO INSPECCIONES SPA' --rut '77.755.694-0'

# Проверить готовый CVE: пройти CAPTCHA в открытом окне и нажать Enter в терминале.
.venv/bin/python -m src.sites.dequienes --cve ACiWqbFTpsmy --interactive

# Импорт сохранённого HTML Legal без браузера и сети.
.venv/bin/python -m src.sites.dequienes --html legal.html --discover-only \
  --company-name 'AERO INSPECCIONES SPA' --rut '77.755.694-0'
```

`--interactive` требует доступного графического рабочего стола. Профиль задаётся
`--profile` (по умолчанию `data/dequienes-profile`); повторный запуск использует
сохранённую сессию. Один профиль нельзя открывать одновременно в двух процессах.
Без `--interactive` RES получает статус `captcha_required`.

`records.json` и `report.json` сохраняются в `--output` (`data/dequienes`).
PDF проходят проверку сигнатуры, EOF и размера, получают SHA-256; валидные уже
сохранённые PDF повторно не скачиваются. Имя файла — SHA-256 от CVE, чтобы
сохранить различие регистров на любой файловой системе.

## Текущие границы

Это первая интерактивная ветка, а не подтверждённый автономный массовый сбор.
Выбор компании и переход Legal требуют участия пользователя; импортируется
только текущая страница таблицы. Пагинация Legal и автоматический выбор компаний
ещё не реализованы: DOM результатов недоступен без входа. Название/RUT для
импорта передаются явно. Источники, отличные от RES, отмечаются
`unsupported_source`. Выдача PDF после CAPTCHA ещё требует проверки с аккаунтом
и ручным прохождением проверки. Если Link ведёт на viewer или редирект,
это фиксируется как `download_failed`, HTML не сохраняется под видом PDF.

Проверка параллельного режима: 12 публикаций, 4 вкладки, `--delay 0.3`,
12 собраны без ошибок. Артефакты: `data/dequienes-companies-parallel-pilot`.
Использован ранее проверенный профиль; свежий профиль в отдельной попытке
остановился на Cloudflare до обработки публикаций.
