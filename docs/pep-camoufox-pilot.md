# Camoufox: проба одной декларации

Установлено и проверено 2026-11-04: Camoufox Python 0.5.9, браузер
158.0.1-beta.41, Playwright 1.62.0. Архив браузера проверен по SHA-256
официального релиза; модель fpgen также проверена установщиком. Запуск и
закрытие браузера на `about:blank` прошли успешно.

Команда для установленной копии (сама задаёт пути к зависимостям и кэшу):

```bash
scripts/camoufox.sh version
scripts/camoufox.sh test
```

Скрипт `scripts/pep_camoufox_pilot.py` берёт одну ссылку из прежней Firefox-выборки,
открывает её в Camoufox/Firefox, нажимает штатную кнопку первой современной
декларации и сохраняет ZIP/PDF только после проверки содержимого. Токен
reCAPTCHA получает и отправляет сама страница; скрипт его не читает и не пишет
в отчёт. HTTP-редирект и сообщение об отказе записываются в `report.json`.

Зависимость ставится в отдельный каталог, потому что Camoufox 0.5.9 требует
Playwright <1.63, а основной проект использует 1.64:

```bash
.venv/bin/python -m pip install --target .camoufox-deps -r requirements-browser-camoufox.txt
export PYTHONPATH="$PWD/.camoufox-deps:$PWD"
export XDG_CACHE_HOME="$PWD/data/camoufox-cache"
.venv/bin/python -m camoufox fetch
.venv/bin/python scripts/pep_camoufox_pilot.py --index 1
```

По умолчанию используется `data/pep-firefox-10-20261103T132909Z/sample.json`.
Можно передать другой `--sample` и номер строки выборки через `--index`.
Один запуск отправляет максимум одну форму скачивания и создаёт отдельный
`data/pep-camoufox-pilot-<UTC>/` с профилем и отчётом. Успешный архив
проверяется существующим `save_payload`, PDF перепроверяется по manifest.

Для доверенной TLS-цепочки скрипт берёт закреплённый Sectigo intermediate из
`data/pep/ca-bundle.pem`, проверяет его подпись против системных корней и
добавляет в собственный NSS-профиль как промежуточный сертификат без root trust.
Проверка TLS остаётся включённой. Установка `certutil` и `openssl` обязательна.
Используется виртуальный дисплей Xvfb; настройка системного Firefox не меняется.

## Проверка десяти ссылок, 2026-11-04

```bash
export PYTHONPATH="$PWD/.camoufox-deps:$PWD"
export XDG_CACHE_HOME="$PWD/data/camoufox-cache"
.venv/bin/python -u scripts/pep_camoufox_batch.py
```

Итоговый прогон: `data/pep-camoufox-10-20261104T102148Z/report.json`.
Выборка совпадает с Firefox: SHA-256
`56c1004837adf6930dc3a5b84737b25b3e67a995f206dcfb814ce8d68f9237ca`.
Один новый профиль/браузер, без прокси, виртуальный дисплей, TLS включён,
пауза 3 секунды, максимум одна отправка каждой формы. За 626 секунд:
3 ссылки completed (№1, №2, №9), 1 partial (№3), 6 failed (№4–8 и №10).
Сохранены 6 PDF и 6 ZIP; все manifest/SHA-256/PDF и CRC архивов повторно
проверены, повреждений нет. На №3 третий POST был отправлен, но ответ и
скачивание не наблюдались до таймаута. Остальные ошибки — сетевые таймауты
навигации/ожидания таблицы; явного сообщения об отказе reCAPTCHA не обнаружено.
Это не подтверждает стабильные 10/10 и не позволяет приписать сбои CAPTCHA.

Предшествующие каталоги `pep-camoufox-10-20261104T101253Z`, `101534Z`,
`101638Z`, `101913Z` содержат диагностические запуски после ошибок сети
и изменения адаптера; их не суммировать с итоговым прогоном как единый тест.
Добавленная проверка глобальной переменной `grecaptcha` была удалена:
Camoufox выполняет Playwright JS в изолированном контексте, где глобальные
переменные страницы недоступны. Используется штатный клик по кнопке сайта.
