# Сравнение маршрутов получения CVE, 2026-11-10

## Прямая проверка RES

Открыта форма BuscarActuaciones2.aspx через Camoufox без аккаунта DeQuienes.
Выбран Registro Sociedades, поиск по RUT, нажата штатная галочка reCAPTCHA и
кнопка Buscar. Запросы сервера в обоих случаях вернули HTTP 200 и Result=OK.

- AERO INSPECCIONES SpA, 77.755.694-0: получена строка CONSTITUCIÓN от 07-05-2023,
  номер обращения 6301603, CVE ACiWqbFTpsmy. Код совпадает с примером Tango.
- AGRICOLA NANCAGUA, 78.054.070-2: явное сообщение «no se encontraron registros».

Первый снимок результата AERO через 3 секунды содержал только заголовки таблицы.
При ожидании строк таблицы результат появился. Нельзя считать отсутствие строк
сразу после domcontentloaded доказательством отсутствия данных. Нужно ожидать
либо заполненные строки, либо явное сообщение об отсутствии записей/ошибке.

Видимая галочка CAPTCHA стала отмеченной; промежуточная проверка boolean
getResponse() при этом оставалась false. Окончательным критерием в эксперименте
был ответ штатной формы и полученная выдача, а не этот вспомогательный boolean.
Проверка CAPTCHA не обходилась, токены не подставлялись и не подделывались.

Выборка из двух запросов подтверждает работоспособность маршрута, но не
массовую стабильность и не процент отказов. PDF в этом эксперименте не скачивался.
Артефакты: data/res-search-pilot/submitted_report.json, aero-result.json,
aero-result.html и снимки экрана. Первоначальный report.json — промежуточная
проверка до отправки формы, а не итог поиска.

## Два маршрута

1. DeQuienes: компания → Legal → CVE с источником RES → официальный
   VerificarCertificados.aspx → CAPTCHA → PDF. Требуется аккаунт DeQuienes и
   доступные запросы; API заявлен в Enterprise, его точные квоты нужно уточнять.
2. Прямой RES: BuscarActuaciones2.aspx → поиск компании по RUT/названию →
   CAPTCHA → список действий с CVE → VerificarCertificados.aspx → PDF.
   Аккаунт DeQuienes не нужен. Реестр ищет только созданные/мигрированные в RES
   юридические лица; пустой результат не означает поломку сайта.
